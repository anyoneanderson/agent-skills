# PR and Issue bodies

Type: `pr`. Usual mode: `argument`.

Explain the problem, changed behavior and acceptance or review decisions. Link detailed evidence instead of reproducing the work log.

Keep acceptance checklists, identifiers and required template headings.

Do not promote test counts into proof of correctness or describe unperformed checks as done.

Stylistic checker candidates omitted: none.

An omission is not a pass verdict. Review unclear meaning in context.
