# Manuals and procedures

Type: `manual`. Usual mode: `argument`.

Keep steps in execution order and name the action, expected result and supplied recovery instructions.

Keep numbered steps, checklists, repeated imperative endings and exact UI labels.

Do not merge steps when order matters or guess a missing button, permission or recovery action.

Stylistic checker candidates omitted: `label-colon`, `uniform-endings`, `uniform-length`, `bullet-ratio`.

An omission is not a pass verdict. Review unclear meaning in context.
