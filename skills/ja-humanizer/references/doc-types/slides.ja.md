# スライド

種類: `slides`。通常のモード: `argument / narrative`。

指定されたスライド構成と読者に合わせる。標語を足さず、各項目の内容が伝わる形にする。

短い句、名詞の見出し、箇条書き、意図した短文を残す。文章の文長目標をスライドの断片へ当てない。

短く収めるために条件を削ったり、断定を強めたりしない。

検査で外す形式上の候補: `label-colon`, `uniform-endings`, `uniform-length`, `bullet-ratio`, `copy-fragments`, `heading-sentence`, `rhythm-mismatch`.

除外は合格判定ではない。意味が曖昧な箇所は文脈を読んで確認する。
